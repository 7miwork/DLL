INSTRUCTION TO UNZIP THE CAMERA PACKAGE:

\----------------------------------------



These files have to be uncompressed into the "Euresys\\MultiCam\\Cameras" folder available in the Public Documents folder.



By default:



&#x20;- For Microsoft Windows XP, this folder is: 

&#x09;C:\\Documents and Settings\\All Users\\Documents\\Euresys\\MultiCam\\Cameras.



&#x20;- For Microsoft Windows Vista and Windows 7 Operating System, this folder is: 

&#x09;C:\\Users\\Public\\Documents\\Euresys\\MultiCam\\Cameras.



&#x20;- For a Linux Operating System, this folder is: 

&#x09;/usr/local/euresys/multicam/cameras.



If the MultiCam driver has been installed in another directory than the default one, uncompress the files accordingly.



C:\\Users\\Public\\Documents

C:\\Users\\Public\\Documents\\Euresys\\MultiCam\\Cameras
